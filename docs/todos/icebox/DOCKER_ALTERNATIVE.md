# Investigate Docker Desktop Alternatives

## Problem

Docker Desktop is resource-heavy on macOS. Want hands-on experience with alternatives.

## Candidates

- **OrbStack** — fast Docker Desktop replacement for macOS, drop-in compatible
- **Podman** — daemonless, rootless, Docker CLI-compatible
- **Colima** — lightweight, Lima-based, supports Docker or containerd backends
